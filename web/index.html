밥길 포인트

식당에서 쌓은 포인트,
카페에서도 그대로.

메뉴를 골라 충전한 토큰(BGP)과 포인트로 결제하면, 매장이 주문을 접수해요.
결제한 돈은 스마트 컨트랙트 금고에 잡혀 있다가 접수되는 순간 매장으로 정산되고, 거절되면 그대로 돌아와요.

  1. 1충전tKRW → BGP
  2. 2주문·결제메뉴 선택 · BGP + 포인트
  3. 3매장 접수금고 → 매장 정산
  4. 4적립매장이 비용 부담
🎓

지갑을 연결하면 내 잔액과 주문 화면이 보여요.
